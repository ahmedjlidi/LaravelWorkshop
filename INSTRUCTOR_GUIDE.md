# Instructor reference

The completed guide, exact answers, demonstrations, and common mistakes are kept on the `solutions` branch. Save student changes before switching:

```sh
git switch solutions
php artisan optimize:clear
```

Then open `INSTRUCTOR_GUIDE.md`. Run `php artisan test` to verify all completed exercises. See `README.md` for setup, expected starter test failures, data resets, and returning to your saved student work.

This starter contains no runtime solution endpoint or executable answer file.
